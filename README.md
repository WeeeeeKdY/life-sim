# 人生重开模拟器

一个纯前端的文字人生模拟：抽天赋 → 分配属性 → **每年做一次选择** → 结算评级。

**▶ [在线试玩](https://weeeeekdy.github.io/life-sim/)** —— 点开就能玩，手机上也能开。

零依赖、零构建，也可以直接双击 `index.html` 本地跑。

## 玩法

1. **抽天赋**：从 36 个天赋池里随机抽 10 张，选 3 张。有稀有天赋（金色边框）。
2. **分属性**：20 点自由分配到 颜值 / 智力 / 体质 / 家境，单项出生上限 10 点。可以「随机分配」偷懒。
3. **过一生**：**每一年都会抛给你一件事，让你选怎么办**。选完才会翻到下一年。
4. **结算**：按最终属性 + 寿命算分，评 E~SSS 八档。

键盘 `1`~`4` 直接选选项，空格 / 回车翻年。

### 选择不是"加减数值"那么简单

同一个事件，选项之间会拉开三条不同的分岔：

**① 记住你选过什么**（flag）

小时候在课堂上举手还是低头，会写进记忆。十几年后，敢举手的人可能被推荐去演讲，一直沉默的人则遇到完全另一件事。这类"早年选择 → 多年后回响"的链子贯穿一生。

**② 把未来排进日程**（queued follow-up）

有些选项不立刻结算，而是**埋一条几年后的事件**。比如高考完选择"去大厂"，三年后才会出现「大厂三年」这一条，那时你已经换了处境。这类后续事件被标成 `queuedOnly`，**不会**在别的年份被随机抽到——只有真的走过那条路才会遇到。

**③ 属性决定你看得见哪些选项**（gate）

高考那年，智力不够的人**根本看不到**"冲一把名校"这个选项，只看到"稳妥报个一本"。不是选了会失败，是选项压根不存在。这让属性不只是分数，而是**你能想到的可能性**。

## 数值设计

### 寿命

每一年都会重算一次，跟着体质走：

```
寿命 = 38 + 8×√体质 + 2.5×√智力 + 2×√家境 ± 6   （上限 115，下限 25）
```

用平方根是关键：**出生时那 10 点体质极值钱**（0 → 10 差二十多年），但后天攒到 40、60 时边际递减，不至于人人都顶穿 115。

**体质归零不会当场死**——这一点是踩了坑才改的。体质在 70 多次选择里会被反复改写，把它当只有 5 格的血条，必然在第 30~40 年崩盘（第一版中位寿命 29 岁，80% 死于"身体撑不住"）。现在体质只决定**寿命长短**：掉体力 = 少活几年，有缓冲，也读得懂。

### 评分

```
分数 = 寿命 × 0.5 + 8 × √(四属性之和)
```

`8×√` 是为了压住膨胀：人生很长，线性加和会随选择次数线性堆高（实测能刷到 244 分）。

### 评级阈值

八档阈值按 **5000 局实测分布**定的：`SSS 168 / SS 158 / S 145 / A 128 / B 110 / C 92 / D 72 / E 0`

| 策略 | 寿命中位 | 分数 p50 | 分布 |
|---|---|---|---|
| 每步随机点 | 73 | 103 | D 28% / C 36% / B 31% / A 3.6% / E 1.3% |
| 每步选最优（上限） | 106 | 155 | S 43% / SS 37% / A 8% / B 5% / C 4% / D 1% / SSS 1.2% |

两个极端之间就是真人的位置——**看不懂数值、只看文案的人落在中间**，所以 D~B 是常态，S 以上要靠每一步都选对。

## 目录

```
index.html              五个页面的骨架
css/style.css           全部样式（深色 / 移动优先 / max-width 480px）
js/events-a.js          1~18 岁事件（47 条）
js/events-b.js          18~30 岁事件（22 条）
js/events-c.js          26~99 岁事件（45 条）
js/data.js              36 个天赋 + 合并事件池 + 8 档评级
js/engine.js            纯逻辑，UMD，不碰 DOM —— 可注入 RNG，可在 Node 里跑
js/app.js               界面宿主，只管 DOM 和流程
test/sim.js             Node 批量模拟 + 数据校验（47 项）
test/ui-drive.html      无头浏览器驱动完整交互流程（55 项）
test/layout-check.html  320px 窄屏布局检查（30 项）
```

事件池按人生阶段拆三个文件——单文件一千五百行没法维护。`js/data.js` 只负责拼起来。

引擎不依赖 DOM，所以同一份逻辑既跑在浏览器里，也跑在 Node 测试里：**改数值只用改数据文件，改完跑测试就能看到分布变化**。

## 加事件

事件长这样（这是真实存在的 `p05`）：

```js
{
  id: 'p05', minAge: 7, maxAge: 12, weight: 8, once: 1,
  text: '老师提了个问题，全班没人举手。你知道答案。',
  options: [
    {
      text: '举手，站起来回答',
      effects: { INT: 1, CHR: 1 },
      reply: '你说对了，老师说以后多举手。',
      set: 'brave',                 // 记一个 flag（'!x' 表示删除）
      then: 't05'                   // 把 t05 排进日程（默认下一年）
    },
    { text: '低头，假装在想', effects: { INT: 1 }, set: 'timid', reply: '…' },
    { text: '小声跟同桌说了答案，让他举手', effects: { CHR: 1, INT: 1 }, reply: '…' }
  ]
}
```

两个进阶字段，各举一个真实例子：

```js
// 门槛：智力不到 9，「最后过一遍错题本」这个选项根本不显示（g01 高考）
{ text: '最后过一遍错题本，十一点睡', need: { INT: 9 }, effects: { INT: 2, STR: -1 }, then: 'g_top' }

// 延迟排队：选了「去大厂」，三年后才长出「大厂三年」那条事件（y10）
{ text: '去大厂，钱多但累', then: 'a01', thenDelay: 3 }
```

`need` 也支持区间 `{ INT: [0, 4] }`，以及 `{ flag: 'x' }` / `{ noFlag: 'x' }`。

`test/sim.js` 会替你查：id 重复、`then` 指向的事件不存在、效果里属性名拼错、有没有哪一年断档没人可选。

## 测试

```bash
node test/sim.js          # 默认 500 局（可传次数: node test/sim.js 5000）
```

47 项断言，覆盖：数据完整性、选项挂起/结算、`need` 门槛、flag 分支命中、`then` 延迟触发、死亡与寿命上下限、同种子可复现、批量模拟不卡死不早死、评级阈值单调。

浏览器侧两个测试需要一个 Chrome：

```bash
CHROME="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"

# 交互流程（55 项）
"$CHROME" --headless=new --disable-gpu --no-sandbox --allow-file-access-from-files \
  --dump-dom --virtual-time-budget=30000 \
  "file://$PWD/test/ui-drive.html" 2>/dev/null | sed -n '/<pre id="report">/,/<\/pre>/p'

# 320px 窄屏布局（30 项）
"$CHROME" --headless=new --disable-gpu --no-sandbox --allow-file-access-from-files \
  --dump-dom --virtual-time-budget=30000 \
  "file://$PWD/test/layout-check.html" 2>/dev/null | sed -n '/<pre id="report">/,/<\/pre>/p'
```

交互测试里最关键的一条：**待选时「下一年」必须点不动**。不然玩家能一路翻年把选项全部跳过去。

布局测试会临时把 `.screen` 的 transition、`.entry` 和 `.choices` 的 animation 全关掉——headless 的虚拟时间下动画采样不确定。这个坑踩了两次，两次都误报成"元素溢出/盖住底部栏"，其实只是量到了动画中间态（`translateY(14px)`，而溢出的正好是 14px）。

## 调平衡踩过的坑

1. **「体质 -1」别堆太多**。选项里体质负向项有 84 个、正向 67 个，均值 -0.087，一生累积 -6，而出生只有 5 点——随机玩的人中位寿命 36 岁、80% 死于身体撑不住。解法见上面寿命那一节。
2. **后续事件必须标 `queuedOnly`**。`a01`（大厂三年）、`g_top`（名校录取）这类事件本来只该由 `then` 触发，但它们的年龄窗口也覆盖正常年份，结果没走过那条路的人也会随机撞上。测试里就是靠"延迟未到时不该触发"这条断言抓出来的。
3. **终局事件的权重要小到反直觉**。`weight: 1` 看着很低，但它在 80 年里每年都在抽，累计能让 66% 的人死于意外/病故。现在给的是 0.03 和 0.05。
4. **评级阈值要按实测分布定，不能拍脑袋**。第一版把 SSS 设在 230，而实际最高分才 146——前四档永远够不着。

## 想继续加的话

- 更多天赋/事件：往 `js/events-*.js` 里加，`test/sim.js` 会帮你查错。
- 属性上限：`js/engine.js` 里的 `ATTR_CAP_BIRTH`（出生）和 `ATTR_MAX`（后天）。
- 存档：`js/app.js` 的 `loadStats/saveStats`，目前只存「活过几次」和最高分。
